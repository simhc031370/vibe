# 품목내역 작성

영수증이나 견적서를 학교 품목내역 서식의 엑셀 파일로 바꿉니다.

xlsx 견적서는 표를 직접 읽습니다. PDF와 사진(JPG, PNG 등)은 글자가 분명할 때만 품목으로 올리고, 확실하지 않으면 줄을 만들지 않습니다. 내려받기 전에 표에서 고칠 수 있습니다.

파일을 올리면 화면에 품목내역이 같은 다섯 열로 채워집니다. 내려받는 `품목내역(통합).xls`는 그 서식을 복사한 뒤 품목만 채웁니다. 시트 이름 `품목내역`, 머리글 `내용`, `규격`, `단위`, `수량`, `예상단가`, 글꼴, 채우기, 열 너비를 유지합니다. 그 외의 열은 넣지 않습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

```bash
npm test
npm run build
```
